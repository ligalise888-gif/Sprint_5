# Sprint_5

Автотесты для сервиса Stellar Burgers - учебного сайта с космическими бургерами.

Проект написан на Python с использованием Selenium и pytest.

## Что проверяется

- регистрация нового пользователя
- ошибка при регистрации с коротким паролем
- вход в аккаунт с четырёх разных страниц: с главной, из личного кабинета, со страницы регистрации, со страницы восстановления пароля
- переход в личный кабинет
- переход из личного кабинета в конструктор через кнопку "Конструктор" и через логотип
- выход из аккаунта
- переключение между вкладками в конструкторе: Булки, Соусы, Начинки

## Структура проекта

В папке tests лежат:
- conftest.py - фикстуры для запуска браузера и регистрации тестового пользователя
- locators.py - все локаторы элементов страницы
- helpers.py - генерация email и пароля, функция входа в аккаунт
- urls.py - адреса страниц сайта
- test_stellar_burgers.py - сами тесты

## Как запустить

Установить зависимости:

pip install -r requirements.txt

Запустить тесты:

pytest

Тесты запускаются в Google Chrome.
